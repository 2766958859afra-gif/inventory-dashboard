一、看板概述

「滤清备货库存看板」是配件事业部门2部门滤清品类的库存数据和分析看板，覆盖 1,251+ SKU（苏雨晴，方静敏，尹芳，戴杨芳，张紫莹，陈景，向海），5 个板块：进销存总览 / 库存结构 / 库销比分析 / 库存变化 / 运营洞察。

核心特点：SC/VC 双口径分离、库销比 6 维度（FBA/PO/可用/离岸/成品/全链路）、运营洞察 5 级预警（断货→正常→动销→积压→沉睡）、库存变化基线对比。

三、数据来源（抓取位置）

字段来源说明
FBA可用 / FBA在途BI/ERP 接口
erp-mcp-inventory → list_suncent_inventory		warehouseType=FBA 的 availableQty / onwayQty（头程在途）。BI实时优先，保留实时值
海外仓可用 / 在途同上海外仓（非FBA非国内仓）availableQty / onwayQty。BI实时优先
本地仓可用同上宁波/深圳/样品/本地/速卖通仓库 availableQty。BI实时优先
采购在途模板（BI接口为0时）进销存报表「采购在途库存」/ 库存明细「采购在途（剩余订单）」
PO在库 / PO在途 / PO近30天销量 / 库龄超90天PO模板「VC库存销售汇总」BI 抓不到，从模板导入（同SKU多行取最大值）
近30天销量模板「运营综合分析明细」BI 抓不到。按 sku 聚合「出库销量」（日/周/月维度均可）
IFS待发货模板「IFS待发货」BI 抓不到。IFS系统导出「发货需求」，按商品编码聚合发货数量（下载教程见模板使用说明子表）
库龄分档（0-30/31-60/.../365+天）模板「库龄报表」BI 抓不到，按商品编码聚合
入库数量（近7/14/30天）模板「进销存报表」BI 抓不到；或板块4按「上周在途−本周在途」推算
运营 / 品类 / 等级 / 状态 / 产品编码映射表（板块1下方 ASIN-运营映射表）1,250 条权威映射；运营也可由「运营综合分析明细」运营列识别
箱规（单箱数量）静态内嵌（你下载的「库存数据」表）「单箱数量」列，1870商编（板块6 BTR 用）
VC渠道标记（is_vc）模板导入（VC库存销售汇总）表里出现过的 SKU 自动标记（板块6 BTR 用）
数据优先级：BI/ERP 实时字段（FBA/海外仓/本地库存）默认保留实时值；BI 抓不到的（PO、销量、IFS、库龄、入库、采购在途）从模板对应子表抓取，不混用。

四、各板块使用教程

📋 板块1 进销存总览

怎么用

  • ① 点顶部「导入数据（总表）」展开 → 下载「库存看板数据-模板.xlsx」
  • ② 下载系统报表 2 个表去表头行后粘贴到模板对应子表（IFS待发货 / 运营综合分析明细）——谁导出的表都能导入，看板按 ASIN-运营映射表自动归属运营（当前仅有向海的销量导出权限就先导自己的，拿到全量后继续导入即可）
  • ③ 保存后点「选择文件」上传 → 看导入日志确认每个子表解析行数
  • ④ 右上角切换数据源（FBA/PO/海外仓/本地）并导出CSV

逻辑

  • 没填的字段自动用 BI/ERP 实时数据；填了以你填的为准（进销存报表优先级最高）
  • 汇总表：FBA可用/在途、PO在库/在途、海外仓、本地、总30天销量 + 5 个库销比
  • 下方「ASIN-运营映射表」：可折叠/搜索/导出CSV（运营归属在这里维护）

📊 板块2 库存结构

怎么用

  • 顶部切换 全部/SC/VC 口径看「各运营·库存构成」
  • 下方 6 个图表：SC vs VC 销量、品类库存分布、运营/品类库销比（6维度）、商品状态分布

逻辑

  • 口径：SC=FBA可用+采购在途+本地；VC=PO在库+在途+海外仓+采购在途+本地
  • 库销比6维度：FBA=(可用+在途)/销量；PO=(在库+在途)/销量；可用=(FBA可用+PO在库)/销量；离岸=海外全部/销量；成品=离岸+本地/销量；全链路=成品+采购在途/销量

📈 板块3 库销比分析

怎么用

  • 筛选栏：搜索SKU/ASIN、品类、运营、渠道（SC/VC/双链路）、状态、等级
  • 点表头排序；📥 导出CSV
  • 「SC vs VC 库销比对比」：差异大→建议转移购物车

逻辑

  • 判断标准：可用库销比=(FBA可用+PO可用)/近30天销量 —— <2 断货风险 / 2-4 正常 / 4-7 需动销 / >7 积压 / 0销量=沉睡
  • 数据来源：库存=BI实时；销量=运营综合分析表；属性=映射表

📦 板块4 库存变化

怎么用

  • 0库存到货统计表（顶部）：断货ASIN（FBA+PO均无）按总在途排序，看预计回货周（总在途÷周均销量，≤4周标红）→ 运营安排推广
  • 渠道周对比表：每渠道 W33在库/W34在库/新增到货/消耗发走/在库Δ
  • 运营维度统计：每运营 FBA纯滚入 / PO纯滚入 / 在库在途 / 可用Δ / 在途Δ
  • ASIN 明细：FBA纯滚入 / PO纯滚入 / 在库实际(Δ) / 在途实际(Δ)，下拉筛选 ΔFBA/Δ海外仓/ΔPO/Δ本地 + 数量下限
  • 📥 导出CSV

逻辑

  • 纯滚入 = 本周在库 − 上周在库 + 实销（把卖掉的加回来，排除销量干扰 = 纯滚进来的货）
  • 只看 FBA 和 PO 两个渠道（会产生销售）；海外仓/本地不产生销售只展示净变化
  • 实销：FBA 用 FBA实销、PO 用 PO实销（周维度数据导入后自动优先，否则用近30天实销）
  • 每周一更新数据后自动与上周一对比（SKU级周快照保留8周）

⚠ 板块5 运营洞察（风险预警）

怎么用

  • 顶部 全部/SC/VC/双链路 大按钮切换渠道（断货ASIN按历史归属）
  • 右侧输入可用库销比区间筛选（如 0-2 看断货风险）；表头排序；📥 导出CSV

逻辑

  • 5 级预警：断货风险(≤2) / 正常(2-4) / 需要动销(4-7) / 库存积压(>7) / 沉睡(0动销)
  • 断货的链接或高库销的链接都要重点处理

🚚 板块6 海外库存预警

怎么用

  • 类型1：PO在库<20 且 海外仓>20（海外仓有货，建议提报BTR）
  • 类型2：PO在库<20 且 海外仓<20 且 海外仓在途<20（两端都缺，建议发货海外仓防断货）
  • 每行「是否不来单」下拉 + 备注框 自动保存（本浏览器）；📥 导出CSV

逻辑

  • 仅统计 VC 渠道 SKU（VC表出现过的=is_vc=1；未上VC的不统计）
  • 商编 = KX/PT 开头的商品编码；箱规 = 库存数据表「单箱数量」（1870商编内嵌，多箱规并列如 1/39/40）

⚙ 设置（运营个人机器人提醒）

怎么用

  • 右上角「⚙ 设置」→ 每位运营（向海/张紫莹/戴杨芳/尹芳/雷冰洁1/陈景/方静敏）一行
  • 填自己钉钉机器人的 Webhook → 勾选订阅内容（BTR/0库存/断货/库龄/IFS）
  • 选推送日期：勾选星期几（快捷：每日 / 隔日一三五 / 隔日二四六）+ 具体时间（HH:MM）
  • 💾 保存全部设置 → 🚀 测试按钮立即推一条

逻辑

  • 每个机器人只推送该运营自己的数据（按运营维度过滤，不涉及他人）
  • 本机服务每10分钟检查一次，到点 ±5分钟推送；同一天同一时段不重复
  • 苏雨晴/PHILTOP 未开放（可联系管理员）

五、更新机制

每日 15:00 cron 自动拉取 ERP 库存（1251 SKU 分批）→ 更新 data.json → 推 GitHub Pages。快照机制：跨天更新时自动把当前值存为 prev_snapshot，作为次日库存变化对比基线。

六、故障排查

现象排查步骤
数据时间不是今天每日15:00自动更新；如失败可手动触发或联系看板负责人
某个SKU的运营为空导入「运营综合分析明细」时保留运营列，或映射表补充后重新导入
库存变化显示无对比需要跨天两次数据（第一次是基线）
图表空白/页面异常强制刷新 Ctrl+Shift+R；仍异常则联系负责人并提供浏览器控制台报错
线上数据与ERP对不上先核对数据时间戳；ERP接口仅含库存字段，销量/PO口径请对照分级表
